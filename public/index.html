Getting started

Browser keeps your profiles. Workbench turns a task into a repeatable run.

  1. Start with an automation

    Runs & archives shows current work and saved results. New run lets you choose a bundled automation and enter its inputs.

  2. Build your own flow

    In Flow editor, define the pages and inputs, add actions, and save a draft. Publish it to make that version available in New run.

  3. Schedule repeat work

    Choose an automation, its inputs and the next run time. Workbench must be running. Missed repeating intervals combine into one occurrence.

  4. Keep the result

    When a run finishes, Workbench stops its browser and saves a verified profile archive. If an action is uncertain, inspect it before retrying. Saved profiles appear in Browser.
